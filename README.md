# SecRep School — прототип админа

Статическая копия артефакта Claude, подготовленная для GitHub Pages.

В этой папке заменены демонстрационные ФИО, контакты и суммы балансов. Исходный экспорт без изменений находится в `outputs/secrep-school-prototype`.

## Публикация на GitHub Pages

Workflow `.github/workflows/pages.yml` собирает статические файлы и публикует сайт при push в `main`.
В настройках репозитория включите Pages с источником **GitHub Actions**.
